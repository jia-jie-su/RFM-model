# English version

# RFM Model Analysis

This mini project was created in **Google Colab** for the purpose of conducting **RFM customer analysis**.  
RFM is a method used to categorize customers based on their purchasing history (even the simplest classification includes 8 segments) to better understand each customer’s potential value to the business.

---

## What is RFM?

RFM stands for three key metrics:

- **R = Recency**: How long it has been since the customer’s last purchase  
- **F = Frequency**: How often the customer makes purchases  
- **M = Monetary**: How much money the customer has spent in total  

By scoring customers based on these three indicators, we can classify them into different segments:

- Very Important Members
- Maintained Customers
- Attentive Members
- Key Retention Customers
- Potential Regular Customers
- Sustained Customers
- Standard Potential Customers
- Dormant Members

# RFM 模型分析

这个小项目是在**Google Colab**上面写的，目的是为了做**RFM 客户分析**。  
RFM是一种通过分析用户购买商品历史的方法对用户进行用户分类（最简单的分类方式也有8种），以此理解每个客户对我们的潜在价值。

---

## 什么是 RFM？

RFM 是三个英文单词的缩写：

- **R = Recency（最近一次的购买时间）**：距离上次购买商品多长时间了  
- **F = Frequency（购买频率）**：购买商品的次数  
- **M = Monetary（消费额度）**：一共花了多少钱  

使用以上三个指标给客户打分，就可以根据得分对不同类型的客户进行分类：

- 重要价值客户 
- 重要保持客户 
- 重要发展客户
- 重要挽留客户
- 一般价值客户
- 一般保持客户
- 一般发展客户
- 一般挽留客户
